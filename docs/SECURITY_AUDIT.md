# Local defensive review · 25 November 2026

Reviewed the product list/detail, quote, order/confirmation, contact, health, authentication and admin handlers. Reviewed catalog eligibility, Prisma operations, order and inventory transactions, origin checks, cookie handling, role checks, rendering sinks, redirects and the configured document headers.

- Search accepts trimmed strings of up to 80 characters. Prisma filters constrain active products and eligible variants before ranking. Scoring operates on text without building SQL or evaluating expressions. The suggestions response projects public fields only, returns at most five rows and shares the full shop's eight-result pagination. Inputs render as React text and use URL encoding when navigating.
- API searches with a nonempty query use the existing database-backed global budget of 900 per minute. The panel debounces for 220 ms, cancels superseded requests and ignores canceled responses. Local history contains up to five submitted or selected search terms. Full-page shop requests still require host-level traffic controls for Internet-scale traffic. Rate-limit saturation was not load-tested.
- Rechecked anonymous admin access, missing origin, invalid content type, malformed/oversized JSON, invalid quantities, missing owner session, owner-bound order reads and private cache headers. Authorized admin edits and stock movements use the existing role checks and transaction services. Fixed patch defaults that could inadvertently republish records.
- The quote and order services calculate prices and availability from database variants. Isolated parallel checkout and retry tests verified stock bounds and owner scoping. Demo checkout collects no card details and performs no live charges.
- Deployment uses HTTPS-only guest cookies when a secure origin is configured. Verified local HttpOnly and SameSite attributes, anti-framing, nosniff and production CSP. Next.js still uses an inline-script allowance. Redirect targets inspected in admin pages are fixed internal destinations.
- Only the example environment file is tracked. A filename-only signature scan of source, tests, scripts, Prisma files and workflows found no matching private-key headers or common live-key signatures. This was a scoped check rather than a complete secret-history audit.
- npm audit against the lockfile reported zero known advisories, including development dependencies. [Audit output](evidence/release/dependency-audit.json)

**Release boundary.** The local controls passed their defensive checks. A hosted portfolio still requires private secrets, a dedicated database, constrained demo writes, backup/restore verification, trusted traffic limits and retention. Commercial payment and fulfillment security are outside this demo.
