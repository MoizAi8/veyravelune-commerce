# Portfolio case study checklist
Project title: VEYRAVELUNE — Immersive Luxury Commerce. Role: accurately describe personal contribution and AI-assisted implementation. Fictional independent portfolio project; not client work or operating business.
- Problem: conventional commerce misses tactile product storytelling; integrate editorial 3D with usable shopping.
- Demonstrate sofa/vase motion, catalog, product gallery, cart, demo checkout, admin and DB transaction evidence. Explain mobile fallback and why Next monolith was selected.
- Capture desktop hero, mid-scroll scene, mobile, product detail, cart, confirmation and admin (synthetic data only). Record actual test metrics, stack versions, tradeoffs, deployment status and credits. Do not claim revenue/conversions or commercial readiness.
- README include setup, env names, seed/migrate/test scripts, demo limitations, screenshots, license/asset credits, live link only when verified. GitHub repo name: veyravelune-commerce (availability unverified).
